# Research Code

These files preserve the original thesis experiment scripts. They are grouped by scientific workflow, not converted into a Python package.

Read `../docs/CODE_MAP.md` for primary entry points and `../docs/REPRODUCIBILITY.md` for known path, data, and checkpoint assumptions.

Do not infer that a file is a supported command merely because it has a `__main__` block. Several historical blocks document an experiment with local paths that are no longer part of the repository.

`legacy/` contains scientifically related comparison models and an incomplete PSO prototype. Those files are retained for provenance only and are not supported reproduction entry points.
